# てのひら — 手話練習Webアプリ

日本手話 (JSL) の辞書・指文字・テーマ別レッスン・テーマ別クイズ・手話通訳士 資格試験対策を練習できる静的サイトです。本アプリは日本手話 (JSL) 専用です。

## 起動方法

`index.html` をブラウザで直接開いて利用できます。ブラウザの制約により `file://` ではJSONの読み込みができないため、アプリは `js/local-data.js` の同梱データで動作します。ローカルサーバーまたは通常の静的ホスティングでは `data/jsl.json`、`data/exam.json`、`data/fingerspelling-jsl.json` を読み込みます。

任意でローカルサーバーを起動する場合:

```text
cd C:\Users\user\projects\SignLanguagePractice
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。Pythonがない場合は `npx http-server` など任意の静的サーバー、または `index.html` の直接表示で利用してください。

## 機能

- 辞書: キーワード検索、カテゴリ絞り込み、単語カード・図解表示(画像はタップ/クリックで拡大表示)
- 指文字: 清音46文字・濁音20文字・半濁音5文字・拗音3文字・促音1文字・長音1文字の合計76項目を収録
  - 一覧(五十音表形式)、フラッシュカード(文字→画像 / 画像→文字)、4択クイズ(正答率表示)、辞書の単語を使った綴り練習
- レッスン: あいさつ・数字・自己紹介・日常表現を順に学習
- クイズ: テーマ別4択、選択後の正誤と解説、最終スコア、問題シャッフル
- 資格対策 (手話通訳士試験を意識したオリジナル練習コンテンツ):
  - 模擬試験モード (学科系): 倫理・原則 / 聴覚障害者文化・聴文化 / 通訳場面の対応 / 手話言語学的基礎 の4分野、4択22問。一問ずつ回答→正誤と解説を表示し、最終スコアと分野別正答率を確認できます。問題は毎回シャッフルされます。
  - 実技セルフ練習モード: 日本語のお題文を見て自分で手話表現を組み立て、「模範表現の解説」(手話の説明文 + 辞書リンク) と見比べて自己採点します。お題は10問。

## ASLについて(スコープ外・データのみ保持)

本アプリの画面上にアメリカ手話 (ASL) の言語切替・辞書・レッスン・ラベル等は表示されません。`data/asl.json` と `assets/asl/` は将来の再利用に備えてソースに残していますが、アプリからは読み込まれず、`dist/` にも同梱されません。資格対策の問題文中でASLに日本語で言及している箇所(JSLとの比較説明)はそのまま残しています。

## データを追加・編集する

### 辞書・レッスン・クイズの語彙

1. `data/jsl.json` の `entries` に項目を追加します。
2. `id` は一意にし、`word` (日本語)、`reading` (ひらがな読み。指文字の綴り練習に使われます)、`category`、`description`、`image`、`emoji`、`videoUrl` を設定します。
3. イラストは相対パスで `assets/jsl/` に保存し、`image` に指定します(推奨形式: WebP、1枚10KB前後)。画像がない場合は `image` を空文字にして `emoji` を指定してください。
4. 動画がない場合は `videoUrl` を空文字にします。架空URLを設定しないでください。
5. 直接 `file://` で開く場合は `node scripts/gen-local-data.js` を実行して `js/local-data.js` を再生成してください。

### 指文字

`data/fingerspelling-jsl.json` で管理します。清音46文字の基本形に対し、濁音は手を横に動かす・半濁音は上に動かす・拗音/促音は手前に引く、という本アプリ独自のルールで変化形を表しています。画像とイラスト生成スクリプトは `scripts/gen-assets.js` にあり、再生成すると `assets/jsl/fingerspelling/*.webp` と `data/fingerspelling-jsl.json` が更新されます。

### 資格対策

`data/exam.json` で管理します。

- `areas`: 分野の定義 (`id` と `label`)。模擬試験の分野別正答率に使われます。
- `questions`: 模擬試験の問題。`area` (分野id)、`question`、`options` (4択)、`answer` (0始まりの正解位置)、`explanation` (解説) を指定します。
- `practicals`: 実技セルフ練習のお題。`prompt` (日本語のお題文)、`hint`、`model` (模範表現の解説)、`refs` (解説から辞書にリンクするJSL辞書の単語名の配列) を指定します。`refs` には `data/jsl.json` の `word` に存在する語を指定してください。

`file://` で利用する場合は `node scripts/gen-local-data.js` を実行して `js/local-data.js` を再生成してください。

## dist/ の再生成

`index.html`・`css/`・`js/`・`data/`(`asl.json` を除く)・`assets/`(`assets/asl/` を除く)・`README.md` を `dist/` にコピーします。ASL関連ファイルは除外対象です。

## 補足

イラストはAI生成/未監修の学習補助イラストであり、手話の公式・完全な見本ではありません。地域差や話者差もあります。学習・受験時は、信頼できる手話講師・辞典・試験実施団体の最新情報で確認してください。資格対策モジュールは非公式の練習コンテンツであり、実際の試験問題ではありません。
